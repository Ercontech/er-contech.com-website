# er-contech.com-website

Official website source for Ercontech.

This repository contains the source files, build configuration, and assets for the Ercontech public website. It serves as the digital presence for the company and provides information about services, capabilities, and contact details.

## Overview

The Ercontech website is designed to present the company to clients, partners, and visitors. The project includes marketing pages, supporting assets, and configuration needed to build and deploy the site.

## Features

- Company overview and branding
- Services and capabilities pages
- Contact and inquiry information
- Responsive layout for desktop and mobile
- Deployable static or app-based website setup

## Tech stack

This repository may use a modern static-site or web application stack depending on the implementation currently in place. Common choices for a site like this include:

- HTML / CSS / JavaScript
- React, Next.js, or another frontend framework
- Static site generator tooling
- Deployment via GitHub Pages, Vercel, Netlify, or a custom hosting platform

## Getting started

### Prerequisites

- Git
- Node.js and npm (if the project uses a JavaScript-based build)

### Clone the repository

```bash
git clone https://github.com/Ercontech/er-contech.com-website.git
cd er-contech.com-website
```

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

### Build for production

```bash
npm run build
```
